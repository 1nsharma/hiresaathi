## 🎯 Overview

HireSaathi AI is a comprehensive enterprise-grade AI platform combining **AI Marketing**, **AI Recruitment**, **AI Support**, **Business Automation**, and **App Building** capabilities in a unified workspace.

This is a **complete frontend application** with all modules implemented, featuring a modern dark theme UI with smooth animations and responsive design.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# 1. Extract the project (if downloaded as ZIP)
unzip hiresaathi-ai.zip

# 2. Navigate to project directory
cd hiresaathi-ai

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

The application will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

Output will be in the `dist/` directory.
